# DD Bazar — প্রতিদিনের বাজারদর (বাংলাদেশ)

বাংলাদেশের ৮টি বিভাগের (ঢাকা, চট্টগ্রাম, রাজশাহী, খুলনা, বরিশাল, সিলেট, রংপুর ও ময়মনসিংহ) প্রতিদিনের মাছ, মাংস, মুরগি ও ডিমের খুচরা এবং পাইকারি বাজারদর ট্র্যাকিং পোর্টাল।

- **৮টি বিভাগীয় ফিল্টার:** ডিফল্ট ঢাকা বিভাগসহ দেশের সব বিভাগের আলাদা বাজারদর।
- **খুচরা ও পাইকারি সুইচ:** এক ক্লিকে খুচরা ও পাইকারি দর দেখার সুবিধা।
- **স্বয়ংক্রিয় দৈনিক আপডেট:** GitHub Actions ও Python স্ক্রিপ্টের মাধ্যমে প্রতিদিন সরকারি সোর্স (DAM) থেকে ডেটা হালনাগাদ।
- **SEO ও মোবাইল অপ্টিমাইজড:** দ্রুতগতির রেসপন্সিভ ইন্টারফেস ও স্ট্রাকচার্ড ডেটা।
